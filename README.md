# Sanyog Foundry ERP

Unified Foundry ERP project.

## Run on Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r app\requirements.txt
cd app
python app.py
```

Open: http://127.0.0.1:5000

Demo login:
- Username: admin
- Password: admin123

Current working areas include dashboard, user authority, production plan and job card workflow. The project is structured to extend the remaining departments in the same database/workflow.
